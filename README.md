# LAN WAR

لعبة حرب عسكرية ثلاثية الأبعاد بمنظور الشخص الثالث، تُلعب عبر شبكة LAN محلية (بدون إنترنت).
المحرك: **Godot 4.3+** (GDScript) — الشبكة: ENet + اكتشاف الغرف عبر UDP.

> الحالة: **نسخة محسّنة**: نماذج مفصّلة مبنية بالكود (جندي، أسلحة، 6 مركبات، راجمة M270)،
> مؤثرات وأصوات مولّدة، وواجهة احترافية (بوصلة، رادار، ذخيرة، لوحة MLRS).
> لا توجد ملفات نماذج خارجية؛ للواقعية القصوى استبدل النماذج بملفات glb لاحقًا.

## التشغيل
1. ثبّت Godot 4.3 أو أحدث.
2. افتح `project.godot` من Godot (المرة الأولى تستورد المشروع).
3. اضغط F5.
4. لتجربة سريعة على جهاز واحد: `Debug > Run Multiple Instances > 2+`.
5. على أجهزة حقيقية: افتح في جدار الحماية **UDP 24680 و 24681** على الأجهزة كلها.

الخط العربي: إن ظهرت الحروف مربعات، ضع خط (مثل Noto Sans Arabic) في `assets/fonts/`
ثم `Project Settings > GUI > Theme > Custom Font`.

## بنية المشروع
```
scripts/autoload/cfg.gd      ثوابت اللعبة (فرق، مركبات، أسلحة، حدود)
scripts/autoload/net.gd      الشبكة والغرفة والإعدادات
scripts/ui/                  القائمة والغرفة
scripts/match/match.gd       المباراة، الانتشار، حدود المركبات، النتائج
scripts/match/map_builder.gd الخرائط
scripts/player/soldier.gd    الجندي
scripts/vehicles/vehicle.gd  كل المركبات
```
المضيف هو المرجع (server-authoritative) للضرر وحدود المركبات والنتائج.

## ما الجديد في هذه النسخة
- **ملء الشاشة بالمقاس الصحيح** (`stretch aspect = expand`): لا أشرطة سوداء، والواجهة تتكيّف مع أي شاشة.
- **تدمير احترافي:** المركبات الأرضية تنفجر وتشتعل (الدبابة يطير برجها) وتبقى حطامًا يحترق؛ المروحيات والطائرات تسقط مشتعلة وتتحطم بانفجار كبير.
- **الجندي:** نموذج أنعم (أطراف منحنية، خوذة ونظارة، سترة، حقيبة حسب الفئة) وذراعان بحل IK يمسكان السلاح بشكل صحيح، مع حركة ركبتين وخطوات وجثة عند الموت.
- **شاشة الانتشار:** اختيار المركبة/المكان فقط. الفئة والسلاح يُختاران من **القائمة الرئيسية > تجهيز الجندي والسلاح** (معاينة ثلاثية الأبعاد وإحصائيات) ويُحفظان.
- **الإعدادات:** الصوت، حساسية النظر، دقة الرسوم، حجم أزرار اللمس، الظلال، FPS.
- **القائمة الرئيسية وغرفة LAN:** مشهد سينمائي تدور فيه الكاميرا 360° حول المركبات مع مروحية تحوم وطائرة تدور، وقائمة منزلقة ونوافذ متحركة.
- **مبانٍ تدخلها وتهدمها:** أبواب ونوافذ وسلم وطابق ثانٍ؛ الصواريخ والقذائف تهدم القطع حول الانفجار مع حطام وغبار، ويحدث انهيار كامل عند تضرر معظم المبنى.
- **الأصوات:** مولّدة برمجيًا لكل شيء (طلقات، انفجارات، محركات، جنازير، خطوات، إعادة تعبئة، أبواب، انهيار، نار، رياح، أزرار).
  لاستخدام **تسجيلات حقيقية** ضع ملفات ogg/wav بنفس الأسماء في `assets/audio/` (انظر README هناك) وسيستخدمها اللعب تلقائيًا.
